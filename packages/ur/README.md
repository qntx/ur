# `@qntx/ur`

Uniform Resources (UR) for TypeScript: bytewords, fountain codes, and single- or multi-part UR strings. Transport-only at the root; typed dCBOR is `@qntx/ur/typed` and registry types are `@qntx/ur/registry`. Wire-compatible with [bcur](https://crates.io/crates/bcur).

See the [documentation](https://github.com/qntx/ur/tree/main/docs).
