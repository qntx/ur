---
title: Registry
description: L5 v2 UR application types on @qntx/ur/registry.
---

`@qntx/ur/registry` is L5: `UrCodec` implementations for BCR-2020-006 v2 types. This version ships `seed` (40300), `hdkey` / `keypath` / `coin-info` (40303–40305), `sskr` (40309), `psbt` (40310), and `envelope` (200). Hosts pass a codec into L4 `toUr` / `fromUr`. Optional `codecMap` / `fromUrStringWith` dispatch over a host-provided set.

Requires the optional peer `@blockchaincommons/dcbor@1.0.0-beta.3`. Importing `@qntx/ur/registry` without the peer fails at load. Transport-only hosts that import only `@qntx/ur` may omit it.

v1 `crypto-seed` / `crypto-psbt` and tags 300–311 are not decoded.

```ts
import {
  seedCodec,
  psbtCodec,
  toUrString,
  fromUrString,
  toUr,
  fromUr,
  MultipartEncoder,
  MultipartDecoder,
  UrType,
  type Seed,
  type Psbt,
} from "@qntx/ur/registry";

const seed: Seed = { payload: entropy };
const seedUri = toUrString(seed, seedCodec); // ur:seed/...

const ur = toUr({ bytes: psbtBin }, psbtCodec);
const enc = MultipartEncoder.create(ur, 50);
const dec = new MultipartDecoder({ expectedType: UrType.parse("psbt") });
while (!dec.complete) dec.receive(enc.nextPart());
const recovered: Psbt = fromUr(dec.message()!, psbtCodec);
```

Primary path remains `fromUrString(uri, seedCodec)`. For mixed inbound types:

```ts
import { codecMap, fromUrStringWith, seedCodec, psbtCodec } from "@qntx/ur/registry";

const map = codecMap([seedCodec, psbtCodec]);
const { type, value } = fromUrStringWith(uri, map);
```

Duplicate `tags[0].name` in `codecMap` is `TypeError`, not `InvalidType`. Unknown type is `UnexpectedType`. There is no global registry.

The UR body is untagged dCBOR. Nested HDKey `origin` / `children` / `use-info` are tagged 40304/40305; the top-level UR body is not.

Seed `creation-date` is BCR-2023-008 tag 1 (`CborDate`) only. The historical BCR-2020-006 example with tag 100 is rejected (`CborType`).

Every `Uint8Array` is copied on encode and decode. Mutating a caller buffer after `toUr` / `fromUr` does not change the UR or the decoded object.

`seedDigest(seed)` is SHA-256 of the raw payload bytes (BCR-2021-002), not of the CBOR map. `hdKeyDigestSource` is dCBOR of `[keyData, chainCode | null, coinType, network]`; `hdKeyDigest` is SHA-256 of that source.

Closed CDDL maps: unknown keys are `CborType`. Codecs throw `CborError`; `toUr` / `fromUr` map those to `UrError` with `code: "CborType"`.

SSKR is a 5-byte header plus share-value bstr. Domain thresholds are N (1..=16); the wire stores N-1. Reserved nibble must be 0. This codec does not split or combine shares.

`envelopeCodec` is a validating identity over untagged envelope-content. `assertEnvelopeContent` walks the CASE; depths 0..=64 are accepted (65 frames). It does not elide, encrypt, or sort assertions.

This export does not derive BIP32 keys, sign or finalize PSBTs, split SSKR, or elide Envelope.
