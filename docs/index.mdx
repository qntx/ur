`@qntx/ur` encodes and decodes [Uniform Resources](https://github.com/BlockchainCommons/Research/blob/master/papers/bcr-2020-005-ur.md) (UR): Bytewords, fountain codes, and single- or multi-part UR strings.

The **root** `@qntx/ur` is a **transport-only** contract: opaque payload bytes plus a type token. There is no dCBOR parse and no tag apply/strip on the `.` export. Application types live on `@qntx/ur/registry`. Type `bytes` is host policy; this codec does not refuse it.

L4 lives on `@qntx/ur/typed` and is the first dCBOR parse in this package.

When `fragmentCount === 1`, `Encoder.nextPart` emits a single-part `ur:<type>/<body>`. An ur-rs `Decoder` will not consume that URI. This `Decoder` still accepts ur-rs fountain `1-1`. Fountain goldens match [bcur](https://github.com/qntx/bcur) and ur-rs.

Status: **1.0.0** transport freeze on the `.` export; **1.1.0** adds `@qntx/ur/typed`; **1.2.0** adds `@qntx/ur/registry`; **1.3.0** adds hdkey / keypath / coin-info; **1.4.0** adds sskr; **1.5.0** adds envelope; **1.6.0** adds `codecMap`; **1.7.0** moves the dcbor peer to `beta.3`. `DEFAULT_LIMITS` integers are frozen. Runtime: Node `>=22.12`.
