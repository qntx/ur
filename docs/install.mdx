---
title: Install
description: Add @qntx/ur with bun or npm.
---

```bash
bun add @qntx/ur
```

```bash
npm i @qntx/ur
```

L4 (`@qntx/ur/typed`) and L5 (`@qntx/ur/registry`) need the optional peer `@blockchaincommons/dcbor@1.0.0-beta.3`. Transport-only hosts that import only `@qntx/ur` may omit it:

```bash
bun add @qntx/ur @blockchaincommons/dcbor@1.0.0-beta.3
```

Package name is `@qntx/ur`. The GitHub repository is `qntx/ur.js`.

Supported runtimes: Node `>=22.12` and Bun, matching `@blockchaincommons/dcbor`. The published `dist` is ESM and does not import Node builtins; browser is not a support claim.
