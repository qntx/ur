# bcur-registry

BCR-2020-006 registry types (seed, hdkey, keypath, coin-info, eckey, address, output-descriptor, sskr, psbt, account-descriptor) on the `bcur` typed dCBOR layer — byte- and error-compatible with `@qntx/ur/registry`.
