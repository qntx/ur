# bcur-cli

Command-line encoder/decoder for [Uniform Resources](https://github.com/BlockchainCommons/Research/blob/master/papers/bcr-2020-005-ur.md) (binary name `bcur`), including terminal QR rendering for air-gapped transfer. Wraps the `bcur` crate.

See the [documentation](https://github.com/qntx/ur/tree/main/docs/rust/cli.mdx).
